خطة البناء خطوة بخطوة

طريقة العمل ثابتة في كل خطوة: أحدد لك الملف ومكانه ← أعطيك الكود كاملًا ← تنسخه وتجرّبه ← نكمل. لا ننتقل لخطوة قبل أن تنجح التي قبلها.

0) التجهيز (مرة واحدة)

  1. أنشئ المجلد C:\Projects\cctv-manager.
  2. انسخ كل محتويات المجلد app-starter من هذه الحزمة إلى داخله.
  3. تأكد أن عندك المجلدات: css · js · libs · fonts · icons، وملف manifest.json.
  4. المكتبات (Bootstrap وjQuery وhtml2pdf) والخطوط جاهزة داخل الحزمة، فلا حاجة لتحميل أي شيء.
  5. ثبّت VS Code أو أي محرر يحفظ الملفات بترميز UTF-8 (مهم للعربي). لا تستخدم Notepad العادي.

خطأ شائع: أن يحفظ المحرر الملف باسم index.html.txt. فعّل إظهار الامتدادات في Windows (View ← File name extensions).

1) المرحلة 1: عرض السعر والعملاء

# الملف ماذا نفعل كيف تختبر
1 index.html هيكل الصفحة، الشريط العلوي، التبويبات الأربعة افتحه بالمتصفح وتظهر الأقسام بالثيم الصحيح
2 css/app.css تنسيقات صغيرة خاصة بالتطبيق الشاشات متناسقة مع صور المعاينة
3 js/utils.js دوال مساعدة: escapeHtml، تنسيق المبالغ والتواريخ، تنظيف الهاتف تجربة بالـ Console
4 js/db.js الاتصال بـ IndexedDB وعمليات الحفظ والقراءة حفظ سجل تجريبي وقراءته بعد إعادة تحميل الصفحة
5 js/app.js التنقل بين الأقسام وتحميل الإعدادات الانتقال بين التبويبات بدون أخطاء
6 شاشة الإعدادات بيانات النشاط واللوجو والشروط تُحفظ وتبقى بعد إغلاق الصفحة
7 js/quotes.js نموذج عرض السعر والحسابات (القسم 6 من الوثيقة) الصافي = 6,930 في المثال
8 js/pdf.js توليد الـ PDF بقالب quote-sheet.css عربي سليم، صفحة A4 واحدة
9 زر المشاركة navigator.share للـ PDF + رسالة واتساب نصية تصل على الواتساب
10 js/clients.js قائمة العملاء والبحث البحث بالاسم والهاتف يعمل
11 service-worker.js العمل بدون إنترنت وضع الطيران: التطبيق يفتح
12 الرفع GitHub Pages ثم الاختبار على الآيفون قائمة القبول في الوثيقة (القسم 15)

أول اختبار حاسم (قبل الخطوة 7): صفحة تجريبية صغيرة تولّد PDF عربيًا وتفتحه على الآيفون. إن ظهر الخط مشوهًا نغيّر الأسلوب فورًا قبل بناء الباقي.

5) GitHub: من الصفر إلى الآيفون

أ) أول مرة

  1. أنشئ حسابًا على github.com، ثم New repository باسم cctv-manager (يمكن أن يكون Public لأنه لا يحتوي بياناتك).
  2. افتح CMD داخل المجلد C:\Projects\cctv-manager ونفّذ الأوامر بالترتيب (استبدل USERNAME باسم حسابك):
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/USERNAME/cctv-manager.git
git push -u origin main
  1. في المستودع: Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root) ← Save.
  2. بعد دقيقة أو اثنتين يظهر الرابط: https://USERNAME.github.io/cctv-manager/

ب) على الآيفون (Safari فقط)

  1. افتح الرابط في Safari ← زر المشاركة ← Add to Home Screen.
  2. افتح التطبيق من الأيقونة (وليس من Safari)، وابدأ إدخال بياناتك من هنا.

ج) عند كل تحديث

git add .
git commit -m "وصف قصير للتعديل"
git push

ثم ارفع CACHE_VERSION في service-worker.js قبل الـ commit، وبعد الرفع أغلق التطبيق على الآيفون وافتحه مرتين.

د) ملاحظة: إن فضّلت الرفع اليدوي من موقع GitHub (Add file ← Upload files) فهو يعمل أيضًا، لكن تأكد من رفع المجلدات كاملة مع الحفاظ على أسمائها.

6) أخطاء شائعة

  • تعديل ملف ثم نسيان رفع رقم CACHE_VERSION ⇒ الآيفون يعرض النسخة القديمة.
  • فتح التطبيق في Safari مرة وفي الأيقونة مرة ⇒ بيانات منفصلة. استخدم الأيقونة فقط.
  • وضع / في أول مسار الملفات (/css/app.css) ⇒ لا تعمل على GitHub Pages. اكتب css/app.css.
  • تحميل المكتبات من الإنترنت داخل index.html ⇒ يتعطل التطبيق بدون إنترنت. استخدم المجلد libs.
  • رفع ملف نسخة احتياطية فيه بيانات عملاء إلى GitHub ⇒ ممنوع. الملف .gitignore الموجود في الحزمة يمنع ذلك لأسماء backup-*.json.
  • نسيان viewport-fit=cover ⇒ تظهر مسافات بيضاء حول الشاشة.

7) كيف نبدأ فعليًا

قل لي: "ابدأ المرحلة 1، الخطوة 1" وسأعطيك index.html كاملًا، مع شرح قصير بالعربي وتحذيرات الخطوة.
